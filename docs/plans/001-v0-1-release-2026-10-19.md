# 001 — v0.1 release

**Outcome:** a stdlib-only CLI that turns Claude Code and Codex logs into a shareable, redacted, single-file HTML replay.

**Scope:** Claude Code and Codex parsers, redaction, stats, HTML reel, CLI (`list`/`render`/`stats`), synthetic demo, Pages.
**Non-goals:** hosting/uploading reels, other agents, PyPI release.

## Acceptance criteria → evidence

| Criterion | Evidence | Result |
|---|---|---|
| Parses real logs of both vendors | 383 local logs (Claude Code + Codex) parsed with 0 errors in 4.4 s | pass |
| Usage is not double-counted | `test_claude_parser_should_skip_meta_and_sidechains_and_dedupe_usage` | pass |
| Redaction catches common secrets without mangling code | 8 true-positive and 5 false-positive cases; false positives found on real logs (`tokenizer = …`, `disk-method-…`) are now regression tests | pass |
| Reel cannot execute session content | Adversarial session (img onerror, `</script>`, attribute-breaking link, hostile tool name) loaded in headless Chromium: no execution, no injected elements | pass |
| Reel works offline, light/dark, mobile | Chromium screenshots at 1280 light/dark and 390 px; no console errors; no horizontal overflow | pass |
| Scales to long sessions | 608-event real session → 1.2 MB reel, loads in 0.2 s | pass |
| Installs cleanly | `uvx --from git+https://github.com/wtergan/agentreel` in an empty dir: `list` and `render` work, template packaged | pass |
| Test suite | `pytest`: 27 passed | pass |

**Verdict:** APPROVED for v0.1.

## Residual risks
- Redaction is pattern-based; unknown secret formats and sensitive plain text (names, hostnames) pass through. README says so, and the CLI prints a reminder.
- Log formats are undocumented and may change; parsers ignore unknown record types rather than failing.
- Codex `web_search` calls have no paired result, so they render with a neutral status.
